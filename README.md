# Retail-Analytics-Customer-Intelligence using PostgreSQL and Power BI
End-to-end retail analytics and customer intelligence project using PostgreSQL, SQL, and Power BI to analyze e-commerce transactions, customer behavior, revenue trends, product performance, and regional sales insights.

## Project Overview
This project analyzes the Olist Brazilian E-Commerce dataset to generate insights into customer behavior, revenue trends, product performance, and regional sales using PostgreSQL and Power BI.
The project demonstrates advanced SQL analytics, KPI reporting, customer segmentation, and dashboard development for business decision-making.
